# Draw with Zen mode

Press **F4** or choose **Zen mode** in the main menu under **View**. The canvas and top tool icons remain visible. The title, style panel, Details panel, page tabs, zoom controls, and sharing overlays disappear.

Draw and switch tools with the top toolbar. Click the active **Exit Zen mode** icon at the end of the toolbar or press **F4** again to restore the interface. Narrow windows allow horizontal scrolling through the tool icons.

Your Details, layers, drawing style, and previous icon library state return when you leave Zen mode. You can still open the icon library or an insert dialog deliberately from the toolbar.

While you edit text or record a keyboard shortcut, F4 does not change modes. Finish the edit first or use the toolbar exit icon. Escape retains its normal editing and selection behavior.

Change the Zen shortcut through **Keyboard shortcuts**, in the **View** group. **F5** continues to start full screen presentation. Leaving a presentation returns to the Zen workspace when Zen mode was already active.
